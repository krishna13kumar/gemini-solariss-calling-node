⚡ Quick Answers

Kavya uses these two ways. Instant: when a customer's question closely matches a row, she answers straight from the saved answer — no AI call and no voice synthesis (the audio is pre-generated) — then returns to the question she was asking. Grounded: for everything else, the AI is given all of these answers as approved knowledge, so it can answer related questions in its own words (and still escalates anything these don't cover).
Higher = safer (fewer wrong matches, more questions go to the AI). Use the test box below to tune it.
⚠️ Matching barely tells numbers apart ("3 kW" vs "2 kW"), so keep similar questions in one row whose answer covers every case, rather than one row per number.
